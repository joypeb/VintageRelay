# Documentation Directory (docs)

Planning, domain knowledge, business rules, development design, and user flow documents for Vintage Relay.

## Directory Guide

- **`domain/`**: project background, domain knowledge, early planning, and ideas.
  - [`idea.md`](domain/idea.md): rationale, problem definition, and idea exploration.
- **`rules/`**: business policies, core exchange rules, and system constraints (to be expanded).
  - [`dev/`](rules/dev/): development rules — `common/` (shared rules and Git), `backend/` (FastAPI and SQLite), `frontend/` (Next.js, TS, and Tailwind).
- **`plans/`**: development plans and system/database architecture specifications.
  - [`vintage-relay-plan-v1.md`](plans/vintage-relay-plan-v1.md): initial development plan, core flows, and draft technical specifications.
  - [`database-design-v1.md`](plans/database-design-v1.md): draft database table design.
  - [`api/`](plans/api/README.md): draft API specifications, one document per API function.
  - [`ai-features-v1.md`](plans/ai-features-v1.md): draft AI feature specification (model integration, AI APIs, guardrails).
- **`flows/`**: screen flows and UI/UX interactions.
  - [`screen-flow-v1.md`](flows/screen-flow-v1.md): draft mobile screen flow specification.
  - [`mockup-flow-v1.html`](flows/mockup-flow-v1.html): interactive mobile screen flow mockup.
